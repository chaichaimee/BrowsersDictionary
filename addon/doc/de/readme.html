Browsers Dictionary


Ihr eigenes Sprachwörterbuch für jede Webseite — hören Sie Webseiten so, wie Sie es möchten.


Autor: chai chaimee

URL: https://github.com/chaichaimee/BrowsersDictionary


Einführung


Mit Browsers Dictionary können Sie Ihr eigenes webseitenspezifisches Sprachwörterbuch für NVDA erstellen. Im Gegensatz zum integrierten Sprachwörterbuch von NVDA, das überall gilt, können Sie mit dieser Erweiterung Wort- und Phrasenersetzungen ausschließlich auf bestimmte Webseiten anwenden — so wird eine Regel, die Sie für eine Webseite erstellen, niemals auf eine andere Webseite oder in eine andere Anwendung übertragen.


Sie können verwirrende Beschriftungen umbenennen, lange oder sich wiederholende Texte kürzen oder Phrasen stummschalten, die Sie nie gesprochen hören möchten, und zwar genau bezogen auf die Seite oder Website, auf der sie störend sind. Die Regeln werden beim Surfen live angewendet und können entweder aus einfachen Textübereinstimmungen oder regulären Ausdrücken erstellt werden.


Unterstützte Browser: Firefox, Chrome, Microsoft Edge, Brave, Opera und Internet Explorer.


Diese Erweiterung funktioniert vollständig offline. Es werden keine Daten über das Netzwerk gesendet oder abgerufen — alle Wörterbücher werden lokal auf Ihrem Computer gespeichert.

Tastenkombinationen


Alt+Windows+B
Einmal drücken: Einstellungen von Browsers Dictionary für die aktuelle Webseite öffnen
Zweimal drücken: Die aktuelle Seite als neue Webseite hinzufügen
Dreimal drücken: Die bestehende Konfiguration der aktuellen Webseite bearbeiten

Funktionsweise des mehrmaligen Drückens: Drücken Sie die Tastenkombination schnell hintereinander ein-, zwei- oder dreimal (innerhalb eines Bruchteils einer Sekunde). Wenn Sie zwischen den Tastenanschlägen etwas länger warten, wird die Zählung zurückgesetzt, sodass ein einzelner, langsamer Tastendruck immer als einzelnes Drücken gewertet wird.

Einmal drücken öffnet immer den Haupt-Einstellungsdialog. Es zeigt die Webseite an, die Ihrer aktuellen Seite entspricht, falls eine bereits konfiguriert ist, oder einen ausfüllbaren neuen Eintrag, falls nicht.

Zweimal drücken ist ein Tastenkürzel, um die Seite, auf der Sie sich gerade befinden, schnell als neue Webseite zu registrieren. Hierfür muss NVDA die URL der Seite zuvor erfolgreich erfasst haben; Ist dies nicht der Fall, hören Sie eine Meldung, die Sie auffordert, sicherzustellen, dass Sie sich in einem Browser befinden.

Dreimal drücken springt direkt zum Bearbeiten der Webseite, die bereits für Ihre aktuelle Seite konfiguriert ist. Wenn für diese Seite noch keine Webseite konfiguriert ist, werden Sie aufgefordert, zuerst zweimal zu drücken, um eine hinzuzufügen.

Funktionen


Webseitenspezifische Sprachwörterbücher


Jede hinzugefügte Webseite erhält ihre eigene unabhängige Liste von Wort-/Phraseneinträgen. Ein Eintrag kann entweder sein:


Eine einfache Textersetzung — jedes genaue Vorkommen des Musters wird durch Ihren Ersetzungstext ersetzt.
Eine Ersetzung durch reguläre Ausdrücke — für eine flexiblere, musterbasierte Ersetzung.


Das Ersetzungsfeld leer zu lassen ist eine gültige, bewusste Entscheidung — es bedeutet "nichts sprechen" für dieses Muster, genau wie das Leergelassene Ersetzungsfeld im integrierten Sprachwörterbuch von NVDA.


Beispiel: Auf einer Webseite, auf der ein Chat-Schalter als "btn_send_msg_42" angesagt wird, könnten Sie einen einfachen Texteintrag hinzufügen, der ihn durch "Senden" ersetzt.

Drei Möglichkeiten zur Erkennung einer Webseite


Beim Hinzufügen oder Bearbeiten einer Webseite wählen Sie aus, wie deren Adresse mit der Seite verglichen wird, auf der Sie sich befinden:


Nur Einzelseite — das Wörterbuch gilt nur, wenn die URL exakt übereinstimmt. Am besten für eine Seite, deren Adresse sich nie ändert.
Gesamte Website (Domain) — das Wörterbuch gilt überall auf derselben Domain, unabhängig vom Rest der Adresse. Dies ist die Standardeinstellung und die empfohlene Wahl, da die meisten Webseiten eindeutige Adressen pro Seite oder Sitzung verwenden.
Regulärer Ausdruck — das Wörterbuch gilt für jede URL, die von Anfang an Ihrem Muster entspricht. Nützlich für Webseiten mit einer vorhersehbaren URL-Struktur, die Sie präzise ansteuern möchten.

Automatische Erkennung der aktuellen Webseite


Browsers Dictionary verfolgt die Adresse der Seite, die Sie gerade betrachten, im Hintergrund, sodass es immer weiß, welches Wörterbuch — falls vorhanden — angewendet werden soll. Diese Verfolgung wird aktualisiert:


- Wenn Sie zu einem Browserfenster wechseln.
- Wenn sich der Fokus innerhalb der Seite bewegt (höchstens zweimal pro Sekunde überprüft, um unnötige Belastung zu vermeiden).
- In dem Moment, in dem das Laden einer neuen Seite abgeschlossen ist.


Sie müssen nichts tun, um dies auszulösen — es geschieht automatisch beim Surfen.

Mustererkennung über getrennte Sprachausgaben hinweg


NVDA sagt manchmal eine einzelne Zeile als mehrere getrennte Sprachausgaben an — zum Beispiel den Schaltertyp oder Linktyp, den Text des Links selbst und den darauffolgenden Text. Browsers Dictionary ist darauf ausgelegt, Muster zu erfassen, die genau über diese Grenzen hinweg verlaufen, sodass eine Phrase wie "Nachrichten bis ..." immer noch erkannt und ersetzt werden kann, selbst wenn "Nachrichten" der Text eines Links ist und der Rest direkt darauf folgt.


Sehr lange gesprochene Passagen (über 20.000 Zeichen) werden von der Überprüfung vollständig ausgenommen, da das Durchsuchen so großer Blöcke spürbare Verzögerungen ohne praktischen Nutzen verursacht.

Sicherheitsprüfungen für reguläre Ausdrücke


Jedes Mal, wenn Sie einen regulären Ausdruck speichern — sei es für einen Worteintrag oder für das URL-Muster einer Webseite — überprüft Browsers Dictionary diesen auf zwei Arten:


Schritt 1 — Gültigkeitsprüfung: Das Muster muss tatsächlich als gültiger regulärer Ausdruck kompiliert werden können, andernfalls wird das Speichern mit einer Erklärung verweigert.
Schritt 2 — Prüfung auf unendliche Schleifen: Das Muster wird mit einer bekannten Struktur verglichen, die häufig dazu führt, dass reguläre Ausdrücke bei bestimmten Texten extrem langsam ausgeführt werden (mehrfach verschachtelte Gruppen wie (x+)+). Wenn es dieser Struktur entspricht, hören Sie eine Warnmeldung — das Muster wird jedoch trotzdem gespeichert, da diese Prüfung nicht garantieren kann, dass ein Muster tatsächlich unsicher ist, sondern nur, dass es unsicheren Mustern ähnelt.


Als zusätzliche Schutzmaßnahme beim Surfen teilen sich alle Sprachwörterbuch-Einträge mit regulären Ausdrücken für eine einzelne gesprochene Phrase ein gemeinsames Zeitbudget von 0,1 Sekunden. Wenn dieses Budget aufgebraucht ist, werden alle verbleibenden Einträge mit regulären Ausdrücken für diese Phrase übersprungen, sodass ein einzelnes komplexes Muster Ihre Sprachausgabe nicht spürbar verzögern kann.

Verwalten von Webseiten und Einträgen


Der Einstellungsdialog listet alle Ihre konfigurierten Webseiten auf der einen Seite und die Wörterbucheinträge der aktuellen Webseite auf der anderen Seite auf. Von hier aus können Sie:


- Einen Wörterbucheintrag hinzufügen, bearbeiten oder entfernen (auch erreichbar über die Entf-Taste oder ein Kontextmenü per Rechter Maustaste in der Eintragsliste).
- Eine gesamte Webseite bearbeiten oder entfernen (auch erreichbar über die Entf-Taste oder ein Kontextmenü per Rechter Maustaste in der Webseitenliste).
- Eine Liste von Einträgen aus einer JSON-Datei direkt in die aktuell ausgewählte Webseite importieren.

Importieren von Einträgen aus einer Datei


Sie können Wörterbucheinträge aus einer JSON-Datei stapelweise in die aktuell ausgewählte Webseite laden. Die Datei benötigt eine "words"-Liste, die entweder einfache Textwerte oder vollständige Einträge mit einem Muster, einem optionalen Regex-Schalter und einer optionalen Ersetzung enthält.


Fehlerhafte Einträge werden übersprungen, anstatt den gesamten Import abzubrechen, und Sie erfahren nach Fertigstellung genau, wie viele Einträge hinzugefügt und wie viele übersprungen wurden. Importierte reguläre Ausdrücke durchlaufen dieselben oben beschriebenen Gültigkeits- und Sicherheitsprüfungen.

Automatische Migration der Konfiguration


Wenn Browsers Dictionary Wörterbücher erkennt, die von einer älteren Version der Erweiterung gespeichert wurden (einschließlich einer Version, die unter dem früheren Namen dieser Erweiterung veröffentlicht wurde), kopiert es diese beim ersten Start automatisch an den aktuellen Konfigurationsort. Es geht nichts verloren, selbst wenn an beiden Orten bereits Einträge vorhanden sind — übereinstimmende Webseiten lassen ihre Wortlisten zusammenführen, anstatt dass eine Kopie die andere überschreibt.

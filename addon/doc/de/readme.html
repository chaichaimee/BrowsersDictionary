Browsers Dictionary


Dein persönliches Aussprachewörterbuch für jede Website, genau so gesprochen, wie du es möchtest.


author: chai chaimee

url: https://github.com/chaichaimee/BrowsersDictionary


Einleitung


Mit Browsers Dictionary kannst du ein benutzerdefiniertes „Aussprachewörterbuch“ pro Website für die NVDA-Sprachausgabe erstellen. Wenn eine Website Wörter, Abkürzungen oder Fachbegriffe verwendet, die NVDA unnatürlich vorliest, kannst du ein Text- oder Reguläres-Ausdruck-Muster sowie einen Ersatz definieren. NVDA liest dann deinen Ersatz vor, wann immer dieses Muster auf dieser spezifischen Seite, auf der gesamten Website oder auf einer beliebigen URL erscheint, die deinem Muster entspricht.


Die Erweiterung funktioniert nach der Einrichtung automatisch: Sie überwacht im Hintergrund, welcher Browser-Tab oder welche Seite aktiv ist, und passt die von NVDA auszugebende Sprache in Echtzeit basierend auf den für die aktuellen Website konfigurierten Regeln an.


Upgrade von Invisible?
Browsers Dictionary ist eine erweiterte Version der „Invisible“-Erweiterung. Wenn du Invisible derzeit installiert hast, deinstalliere es einfach zuerst, installiere dann Browsers Dictionary und verwende es sofort weiter. Du musst deine Website-Einrichtungen nicht neu vornehmen: Alle Website-Einstellungen, die du zuvor in Invisible konfiguriert hast, werden beim ersten Start automatisch in Browsers Dictionary übernommen.

Tastenkombinationen


NVDA+Shift+W
Einfaches Tippen : Öffnet die Browsers Dictionary-Einstellungen für die aktuelle Website
Doppeltes Tippen : Erfasst die URL der aktuellen Seite und öffnet den Dialog „Neue Website hinzufügen“

Einmal tippen, um die bereits für die aktuelle Seite gespeicherten Wörterbucheinträge zu überprüfen oder zu bearbeiten. Zweimal schnell tippen, während der Fokus im Browser liegt, um sofort einen neuen Website-Eintrag mit der URL der aktuell angezeigten Seite zu erstellen. Wenn NVDA keine URL für einen Doppeltipp erkennen kann (z. B. weil du dich in keinem unterstützten Browser befindest), wird die Meldung ausgegeben: „URL kann nicht erfasst werden. Stelle sicher, dass du dich in einem Browser befindest.“

Funktionen


Automatische Live-URL-Verfolgung


Browsers Dictionary verfolgt die Seite, auf der du dich befindest, ohne dass du etwas tun musst. Die Aufzeichnung der aktuellen URL wird aktualisiert:


- Wenn du zu einem Browserfenster wechselst (Firefox, Chrome, Edge, Brave, Opera oder Internet Explorer)
- Wenn das Laden einer Seite abgeschlossen ist
- Wenn sich der Fokus auf ein neues Element bewegt, höchstens zweimal pro Sekunde, damit es aktuell bleibt, ohne den Browser zu überlasten


Diese URL verwendet die Erweiterung im Hintergrund, um zu bestimmen, welcher Satz von Wörterbucheinträgen auf das zutrifft, was du gerade liest.

Wort- und Musteraustausch pro Website


Für jede hinzugefügte Website kannst du eine Liste von Einträgen erstellen. Jeder Eintrag hat:


- Ein Muster: den genauen Text oder einen regulären Ausdruck, nach dem gesucht werden soll
- Einen optionalen Ersatz: was NVDA stattdessen sagen soll. Wenn er leer bleibt, wird der gefundene Text einfach aus der Sprachausgabe entfernt
- Ein Kontrollkästchen Als regulären Ausdruck verwenden für fortgeschrittenes Musterabgleichen


Wann immer NVDA Text auf einer passenden Seite vorliest, prüft Browsers Dictionary diesen anhand deiner Liste und ersetzt Übereinstimmungen, bevor die Sprachausgabe erfolgt. Plaintext-Einträge werden zuerst abgeglichen (längste Einträge zuerst, um partielle Überschneidungen zu vermeiden), gefolgt von deinen regulären Ausdrücken.

Drei Wege zum Abgleichen einer Website


Beim Hinzufügen oder Bearbeiten einer Website legst du fest, wie breit die Wörterbucheinträge gelten sollen:


Nur einzelne Seite: Einträge gelten nur für die genaue URL, die du gespeichert hast.
Gesamte Website (Domain): Einträge gelten für jede Seite auf derselben Domain, unabhängig vom spezifischen Pfad.
Regulärer Ausdruck: Einträge gelten für jede URL, die einem von dir geschriebenen Muster entspricht, geprüft ab dem Anfang der Adresse.

Verwaltung von Websites und Einträgen


Der Einstellungsdialog (geöffnet durch einmaliges Tippen von NVDA+Shift+W) enthält eine Websitelist und für die ausgewählte Website eine Eintragsliste. Von hier aus kannst du:


- Ein Wort- oder Mustereintrag Hinzufügen, Bearbeiten oder Entfernen, mit Bestätigung vor dem Entfernen
- Ein Kontextmenü öffnen (oder Entf drücken) auf einer Website oder einem Eintrag für schnelle Bearbeiten-/Entfernen-Aktionen
- Website bearbeiten oder Website entfernen direkt aus dem Kontextmenü der Websitelist
- Eine laufende Bearbeitung abbrechen und zum Hinzufügen neuer Einträge zurückkehren


Das Hinzufügen einer neuen Website öffnet einen dedizierten Dialog, in dem du Anzeigename, URL und Abgleichsmodus festlegst; das Speichern einer neuen Website öffnet sofort den Haupt-Einstellungsdialog für diese Website erneut, sodass du sofort mit dem Hinzufügen von Einträgen beginnen kannst.

Einträge aus einer Datei importieren


Du kannst Einträge mit Aus Datei importieren... in großen Mengen in die aktuell ausgewählte Website laden. Browsers Dictionary liest eine JSON-Datei, die eine „words“-Liste enthält, in der jeder Eintrag eine einfache Zeichenkette (als einfacher Textersatz behandelt) oder ein vollständiges Objekt mit Muster-, Ersatz- und Regex-Einstellungen sein kann. Nach der Bestätigung wird gemeldet, wie viele Einträge hinzugefügt und wie viele übersprungen wurden, beispielsweise weil sie für diese Website bereits existierten.

Regex-Sicherheitswarnungen und Zeitbudget


Um dich vor Mustern zu schützen, die die Sprachausgabe einfrieren oder verlangsamen könnten:


- Wenn du einen regulären Ausdruck speicherst, der den Anschein erweckt, ein unkontrolliertes „katastrophales Backtracking“ (bestimmte verschachtelte wiederholte Gruppen) verursachen zu können, warnt dich NVDA, dass das Muster langsam laufen könnte, sodass du es vereinfachen kannst. Dies ist ein hilfreicher Hinweis, keine harte Sperre; der Eintrag wird trotzdem gespeichert
- Während des Sprechens erlaubt Browsers Dictionary nur eine kurze Gesamtverarbeitungszeit für alle regulären Ausdruck-Einträge auf einem einzelnen Sprachstück. Wenn dieses Budget aufgebraucht ist, werden alle verbleibenden Regex-Einträge für dieses Sprachstück übersprungen, damit deine Sprachausgabe nicht aufgehalten wird
- Extrem lange Textabschnitte werden überhaupt nicht nach Ersetzungen durchsucht, da das Scannen dieser Abschnitte ohne nennenswerten Nutzen Verzögerungen verursachen würde

Nahtlose Migration von älteren Konfigurationen


Browsers Dictionary sucht beim ersten Start automatisch nach Konfigurationsdaten, die von früheren Versionen oder dem vorherigen Namen der Erweiterung „Invisible“ hinterlassen wurden, und führt diese in die aktuelle Konfiguration ein. Websites und Einträge aus einem älteren Layout werden kopiert, ohne etwas zu überschreiben, das du bereits eingerichtet hast; falls bereits eine Datei mit demselben Namen existiert, wird die ältere Kopie als Backup aufbewahrt, anstatt verworfen zu werden. Doppelte Websitedateien, die am Ende dieselbe Website repräsentieren, werden automatisch zusammengeführt, wobei doppelte Einträge in einer Liste kombiniert werden.

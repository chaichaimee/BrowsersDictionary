Browsers Dictionary


Votre dictionnaire de prononciation personnel pour chaque site web, lu exactement comme vous le souhaitez.


author: chai chaimee

url: https://github.com/chaichaimee/BrowsersDictionary


Introduction


Browsers Dictionary vous permet de créer un "dictionnaire de prononciation" personnalisé par site web pour la synthèse vocale de NVDA. Si un site utilise des mots, des abréviations ou du jargon que NVDA lit maladroitement, vous pouvez définir un modèle de texte ou d'expression régulière et un remplacement, et NVDA prononcera votre remplacement chaque fois que ce modèle apparaîtra sur cette page spécifique, sur l'ensemble du site web, ou sur n'importe quelle URL correspondant à votre propre modèle.


Le module complémentaire fonctionne automatiquement une fois configuré : il surveille discrètement quel onglet ou quelle page du navigateur est actif, et réécrit en temps réel la parole que NVDA est sur le point de prononcer, en fonction des règles que vous avez configurées pour le site actuel.


Vous passez d'Invisible ?
Browsers Dictionary est une version améliorée du module complémentaire "Invisible". Si vous avez actuellement Invisible installé, désinstallez-le simplement d'abord, puis installez Browsers Dictionary et continuez à l'utiliser immédiatement. Vous n'avez pas besoin de refaire vos configurations de sites : tous les paramètres de sites que vous aviez configurés dans Invisible sont automatiquement reportés dans Browsers Dictionary lors de sa première exécution.

Raccourcis clavier


NVDA+Shift+W
Appui simple : Ouvrir les paramètres de Browsers Dictionary pour le site actuel
Appui double : Capturer l'URL de la page actuelle et ouvrir la boîte de dialogue Ajouter un nouveau site

Appuyez une fois pour examiner ou modifier les entrées du dictionnaire déjà enregistrées pour la page sur laquelle vous vous trouvez actuellement. Appuyez deux fois rapidement, tout en ayant le focus dans votre navigateur, pour créer immédiatement une nouvelle entrée de site en utilisant l'URL de la page que vous consultez actuellement. Si NVDA ne peut pas détecter d'URL pour un double appui (par exemple, vous n'êtes pas dans un navigateur pris en charge), il vous dira "Impossible de capturer l'URL. Assurez-vous d'être dans un navigateur."

Fonctionnalités


Suivi automatique et en direct des URL


Browsers Dictionary garde une trace de la page sur laquelle vous vous trouvez sans que vous ayez à faire quoi que ce soit. Il met à jour son enregistrement de l'URL actuelle :


- Lorsque vous basculez vers une fenêtre de navigateur (Firefox, Chrome, Edge, Brave, Opera ou Internet Explorer)
- Lorsqu'une page a fini de charger
- Lorsque le focus se déplace vers un nouvel élément, au maximum deux fois par seconde, afin de rester à jour sans surcharger le navigateur


Cette URL est ce que le module complémentaire utilise en arrière-plan pour décider quel ensemble d'entrées de dictionnaire s'applique à ce que vous lisez actuellement.

Remplacement de mots et de motifs par site


Pour chaque site que vous ajoutez, vous pouvez créer une liste d'entrées. Chaque entrée possède :


- Un Motif : le texte exact, ou une expression régulière, à rechercher
- Un Remplacement facultatif : ce que NVDA doit dire à la place. S'il est laissé vide, le texte correspondant est simplement supprimé de la parole
- Une case à cocher Utiliser comme expression régulière, pour la correspondance de motifs avancés


Chaque fois que NVDA s'apprête à prononcer du texte sur une page correspondante, Browsers Dictionary le vérifie par rapport à votre liste et substitue les correspondances avant que la parole ne soit prononcée. Les entrées en texte brut sont comparées en premier (les entrées les plus longues en premier, pour éviter les chevauchements partiels), suivies de vos expressions régulières.

Trois façons de faire correspondre un site


Lors de l'ajout ou de la modification d'un site, vous choisissez l'étendue de l'application de ses entrées de dictionnaire :


Page unique uniquement : les entrées s'appliquent uniquement à l'URL exacte que vous avez enregistrée.
Ensemble du site web (domaine) : les entrées s'appliquent à chaque page du même domaine, quel que soit le chemin spécifique.
Expression régulière : les entrées s'appliquent à toute URL correspondant à un motif que vous écrivez, vérifié à partir du début de l'adresse.

Gestion des sites et des entrées


La boîte de dialogue Paramètres (ouverte par un simple appui de NVDA+Shift+W) contient une liste de sites et, pour le site sélectionné, une liste d'entrées. De là, vous pouvez :


- Ajouter, Modifier ou Supprimer une entrée de mot ou de motif, avec confirmation avant suppression
- Ouvrir un menu contextuel (ou appuyer sur Suppr) sur un site ou une entrée pour des actions rapides d'édition/suppression
- Modifier le site ou Supprimer le site directement depuis le menu contextuel de la liste des sites
- Annuler une modification en cours et revenir à l'ajout de nouvelles entrées


L'ajout d'un nouveau site ouvre une boîte de dialogue dédiée où vous définissez son nom d'affichage, son URL et son mode de correspondance ; l'enregistrement d'un nouveau site rouvre immédiatement la boîte de dialogue principale des paramètres pour ce site afin que vous puissiez commencer à ajouter des entrées tout de suite.

Importer des entrées à partir d'un fichier


Vous pouvez charger en masse des entrées dans le site actuellement sélectionné en utilisant Importer depuis un fichier.... Browsers Dictionary lit un fichier JSON contenant une liste "words", où chaque entrée peut être une simple chaîne (traitée comme un remplacement de texte simple) ou un objet complet avec des paramètres de motif, de remplacement et d'expression régulière. Après votre confirmation, il indique combien d'entrées ont été ajoutées et combien ont été ignorées, par exemple parce qu'elles existaient déjà pour ce site.

Avertissements de sécurité Regex et budget de temps


Pour vous protéger contre des motifs qui pourraient figer ou ralentir la parole :


- Lorsque vous enregistrez une expression régulière qui semble pouvoir provoquer un "retour arrière catastrophique" incontrôlé (certains groupes répétés imbriqués), NVDA vous avertit que le motif peut s'exécuter lentement, afin que vous puissiez le simplifier. C'est une mise en garde utile, pas un blocage strict ; l'entrée est quand même enregistrée
- Pendant la lecture réelle, Browsers Dictionary n'autorise qu'un bref temps de traitement total pour toutes les entrées d'expression régulière sur un seul morceau de parole. Si ce budget est épuisé, toutes les entrées regex restantes pour ce morceau de parole sont ignorées afin que votre parole ne soit pas bloquée
- Les portions de texte extrêmement longues ne sont pas du tout analysées à la recherche de remplacements, car les analyser ajouterait un délai sans avantage significatif

Migration transparente à partir de configurations plus anciennes


Browsers Dictionary vérifie automatiquement les données de configuration laissées par les versions précédentes ou l'ancien nom de module complémentaire "Invisible", et les fusionne dans sa configuration actuelle lors de sa première exécution. Les sites et les entrées d'une ancienne disposition sont copiés sans écraser rien de ce que vous avez déjà configuré ; si un fichier portant le même nom existe déjà, l'ancienne copie est conservée comme sauvegarde au lieu d'être supprimée. Les fichiers de sites en double qui finissent par représenter le même site sont automatiquement fusionnés, les entrées en double étant combinées en une seule liste.

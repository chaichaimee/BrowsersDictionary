Browsers Dictionary


Votre propre dictionnaire de prononciation pour chaque site web — écoutez les pages comme vous le souhaitez.


Auteur : chai chaimee

URL : https://github.com/chaichaimee/BrowsersDictionary


Introduction


Browsers Dictionary vous permet de créer votre propre dictionnaire de prononciation par site web pour NVDA. Contrairement au dictionnaire de prononciation intégré de NVDA, qui s'applique partout, cette extension vous permet d'associer des substitutions de mots et de phrases uniquement à des sites spécifiques — ainsi, une règle créée pour un site web ne s'appliquera jamais à un autre site ni à une autre application.


Vous pouvez renommer des étiquettes confuses, raccourcir des textes meublants ou répétitifs, ou rendre muettes des phrases que vous ne voulez jamais entendre prononcées, le tout limité à la page ou au site où elles vous gênent. Les règles s'appliquent en direct pendant votre navigation et peuvent être créées à partir de correspondances en texte brut ou d'expressions régulières.


Navigateurs pris en charge : Firefox, Chrome, Microsoft Edge, Brave, Opera et Internet Explorer.


Cette extension fonctionne entièrement hors ligne. Elle ne transmet ni ne récupère aucune donnée sur le réseau — tous les dictionnaires sont stockés localement sur votre ordinateur.

Touches de raccourci


Alt+Windows+B
Simple appui : Ouvrir les paramètres de Browsers Dictionary pour le site actuel
Double appui : Ajouter la page actuelle comme nouveau site
Triple appui : Modifier la configuration existante du site actuel

Comment fonctionne l'appui successif : Appuyez sur la combinaison de touches une, deux ou trois fois rapidement (en une fraction de seconde). Attendre un peu plus longtemps entre deux appuis réinitialise le compteur, ainsi un appui lent sera toujours traité comme un simple appui.

Un simple appui ouvre toujours le dialogue principal des paramètres, affichant le site correspondant à votre page actuelle si l'un d'eux est déjà configuré, ou une nouvelle entrée prête à être remplie dans le cas contraire.

Un double appui est un raccourci pour enregistrer rapidement la page sur laquelle vous vous trouvez actuellement comme nouveau site. Cela nécessite que NVDA ait préalablement capturé l'URL de la page avec succès ; si ce n'est pas le cas, vous entendrez un message vous demandant de vous assurer que vous êtes dans un navigateur.

Un triple appui passe directement à la modification du site déjà configuré pour votre page actuelle. Si aucun site n'est encore configuré pour cette page, il vous sera demandé de faire un double appui d'abord pour en ajouter un.

Fonctionnalités


Dictionnaires de prononciation par site


Chaque site que vous ajoutez possède sa propre liste indépendante d'entrées de mots/phrases. Une entrée peut être :


Un remplacement en texte brut — toute occurrence exacte du motif est remplacée par votre texte de remplacement.
Un remplacement par expression régulière — pour une correspondance plus flexible basée sur des motifs.


Laisser le champ de remplacement vide est un choix valide et délibéré — cela signifie "ne rien verbaliser" pour ce motif, exactement comme si vous laissiez un remplacement vide dans le dictionnaire de prononciation intégré de NVDA.


Exemple : Sur un site où un bouton de discussion est annoncé comme "btn_send_msg_42", vous pouvez ajouter une entrée en texte brut le remplaçant par "Envoyer".

Trois façons de faire correspondre un site


Lors de l'ajout ou de la modification d'un site, vous choisissez la manière dont son adresse est comparée à la page sur laquelle vous vous trouvez :


Page unique seulement — le dictionnaire ne s'applique que si l'URL correspond exactement. Idéal pour une page dont l'adresse ne change jamais.
Site web entier (domaine) — le dictionnaire s'applique n'importe où sur le même domaine, quel que soit le reste de l'adresse. C'est le choix par défaut et recommandé, car la plupart des sites utilisent des adresses uniques par page ou par session.
Expression régulière — le dictionnaire s'applique à toute URL qui correspond à votre motif depuis le début. Utile pour les sites ayant une structure d'URL prévisible que vous souhaitez cibler précisément.

Détection automatique du site actuel


Browsers Dictionary suit l'adresse de la page que vous consultez actuellement en arrière-plan, afin de toujours savoir quel dictionnaire de site — le cas échéant — doit s'appliquer. Ce suivi est mis à jour :


- Lorsque vous basculez vers une fenêtre de navigateur.
- Lorsque le focus se déplace dans la page (vérifié au maximum deux fois par seconde, pour éviter tout traitement inutile).
- Au moment où une nouvelle page finit de se charger.


Vous n'avez jamais besoin de rien faire pour déclencher cela — cela se produit automatiquement pendant que vous naviguez.

Correspondance à travers les segments de parole fractionnés


NVDA annonce parfois une seule ligne comme plusieurs segments de parole distincts — par exemple, le rôle d'un lien, le texte du lien lui-même, et le texte qui le suit. Browsers Dictionary est conçu pour intercepter les motifs qui chevauchent précisément ce type de frontière, de sorte qu'une phrase comme "messages jusqu'à ..." puisse toujours être détectée et remplacée même si "messages" est le texte d'un lien et que le reste suit immédiatement.


Les passages parlés très longs (plus de 20 000 caractères) sont totalement ignorés par l'analyse, car chercher des motifs dans de tels blocs entraîne un ralentissement perceptible sans bénéfice réel.

Vérifications de sécurité des expressions régulières


Chaque fois que vous enregistrez une expression régulière — que ce soit pour une entrée de mot ou pour le motif d'URL d'un site — Browsers Dictionary la vérifie de deux manières :


Étape 1 — Vérification de validité : le motif doit pouvoir être compilé en une expression régulière valide, sinon l'enregistrement est refusé avec une explication.
Étape 2 — Vérification de motif infini : le motif est comparé à une structure connue qui entraîne généralement une exécution extrêmement lente des expressions régulières sur certains textes (groupes imbriqués répétés tels que (x+)+). S'il correspond à cette structure, vous entendrez un message d'avertissement — mais le motif sera tout de même enregistré, car cette vérification ne peut pas garantir qu'un motif est réellement dangereux, mais seulement qu'il ressemble à ceux qui peuvent l'être.


Comme protection supplémentaire pendant votre navigation, toutes les entrées de mots en expression régulière pour une même phrase parlée partagent un budget temps combiné de 0,1 seconde. Si ce budget est épuisé, toutes les entrées en expression régulière restantes pour cette phrase sont ignorées pour cette occurrence, afin qu'un motif lourd ne ralentisse pas de manière perceptible la synthèse vocale.

Gestion des sites et des entrées


Le dialogue des paramètres liste tous vos sites configurés d'un côté et les entrées du dictionnaire du site actuel de l'autre. À partir d'ici, vous pouvez :


- Ajouter, modifier ou supprimer une entrée de dictionnaire (également accessible via la touche Suppr ou un menu contextuel par clic droit sur la liste des entrées).
- Modifier ou supprimer un site entier (également accessible via la touche Suppr ou un menu contextuel par clic droit sur la liste des sites).
- Importer une liste d'entrées depuis un fichier JSON directement dans le site actuellement sélectionné.

Importation d'entrées depuis un fichier


Vous pouvez charger en masse des entrées de dictionnaire dans le site actuellement sélectionné à partir d'un fichier JSON. Le fichier doit contenir une liste "words" contenant soit des valeurs en texte brut, soit des entrées plus complètes avec un motif, un indicateur d'expression régulière optionnel et un remplacement optionnel.


Les entrées mal formées sont ignorées au lieu d'arrêter tout l'importation, et on vous indique exactement combien d'entrées ont été ajoutées par rapport à celles ignorées une fois le traitement terminé. Les expressions régulières importées passent par les mêmes vérifications de validité et de motif infini décrites ci-dessus.

Migration automatique de la configuration


Si Browsers Dictionary détecte des dictionnaires enregistrés par une ancienne version de l'extension (y compris une version publiée sous l'ancien nom de cette extension), il les copie automatiquement vers l'emplacement de configuration actuel la première fois qu'il démarre. Rien n'est perdu même si des entrées existent déjà aux deux endroits — les sites correspondants voient leurs listes de mots fusionnées au lieu qu'une copie n'écrase l'autre.

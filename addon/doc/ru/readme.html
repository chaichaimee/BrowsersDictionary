Browsers Dictionary


Ваш персональный словарь произношения для каждого веб-сайта, звучащий именно так, как вы хотите.


author: chai chaimee

url: https://github.com/chaichaimee/BrowsersDictionary


Введение


Browsers Dictionary позволяет создать настраиваемый «словарь произношения» для каждого отдельного сайта для речи NVDA. Если сайт использует слова, аббревиатуры или жаргон, которые NVDA читает неуклюже, вы можете задать шаблон текста или регулярное выражение и замену, и NVDA будет произносить вашу замену всякий раз, когда этот шаблон появляется на этой конкретной странице, на всем веб-сайте или на любом URL-адресе, соответствующем вашему шаблону.


Дополнение работает автоматически после настройки: оно незаметно отслеживает, какая вкладка или страница браузера активна, и в реальном времени перезаписывает речь, которую NVDA собирается произнести, на основе правил, настроенных для текущего сайта.


Обновление с Invisible?
Browsers Dictionary — это улучшенная версия дополнения «Invisible». Если у вас в настоящее время установлен Invisible, просто сначала удалите его, затем установите Browsers Dictionary и продолжайте использовать его сразу же. Вам не нужно заново настраивать какие-либо параметры сайтов: все настройки сайтов, ранее сконфигурированные в Invisible, автоматически переносятся в Browsers Dictionary при первом запуске.

Горячие клавиши


NVDA+Shift+W
Одинарное нажатие : Открыть настройки Browsers Dictionary для текущего сайта
Двойное нажатие : Захватить URL текущей страницы и открыть диалог добавления нового сайта

Нажмите один раз, чтобы просмотреть или отредактировать записи словаря, уже сохраненные для текущей страницы. Дважды быстро нажмите, находясь в фокусе браузера, чтобы немедленно создать новую запись сайта, используя URL просматриваемой в данный момент страницы. Если NVDA не может обнаружить URL для двойного нажатия (например, вы находитесь не в поддерживаемом браузере), программа сообщит: «Не удалось захватить URL. Убедитесь, что вы находитесь в браузере».

Возможности


Автоматическое отслеживание URL в реальном времени


Browsers Dictionary следит за страницей, на которой вы находитесь, без каких-либо действий с вашей стороны. Он обновляет запись текущего URL:


- При переключении на окно браузера (Firefox, Chrome, Edge, Brave, Opera или Internet Explorer)
- Когда загрузка страницы завершена
- Когда фокус перемещается на новый элемент, не чаще двух раз в секунду, чтобы оставаться актуальным без перегрузки браузера


Этот URL дополнение использует в фоновом режиме для определения того, какой набор записей словаря применяется к тому, что вы читаете в данный момент.

Замена слов и шаблонов для каждого сайта


Для каждого добавленного сайта вы можете создать список записей. Каждая запись содержит:


- Шаблон: точный текст или регулярное выражение для поиска
- Необязательную Замену: то, что NVDA должен произнести вместо этого. Если оставить поле пустым, совпадающий текст просто удаляется из речи
- Флажок Использовать как регулярное выражение для расширенного сопоставления шаблонов


Всякий раз, когда NVDA собирается произнести текст на соответствующей странице, Browsers Dictionary сверяет его с вашим списком и подменяет совпадения до того, как речь будет произнесена. Записи обычного текста сопоставляются первыми (самые длинные записи сначала, чтобы избежать частичных наложений), за ними следуют ваши регулярные выражения.

Три способа сопоставления сайта


При добавлении или редактировании сайта вы выбираете степень охвата его записей словаря:


Только одна страница: записи применяются только к точного URL, который вы сохранили.
Весь веб-сайт (домен): записи применяются к каждой странице на том же домене, независимо от конкретного пути.
Регулярное выражение: записи применяются к любому URL, который соответствует написанному вами шаблону, проверяемому с начала адреса.

Управление сайтами и записями


Диалог настроек (открываемый одиночным нажатием NVDA+Shift+W) содержит список сайтов и, для выбранного сайта, список записей. Отсюда вы можете:


- Добавить, Редактировать или Удалить запись слова или шаблона с подтверждением перед удалением
- Открыть контекстное меню (или нажать Delete) на сайте или записи для быстрых действий редактирования/удаления
- Редактировать сайт или Удалить сайт прямо из контекстного меню списка сайтов
- Отменить текущее редактирование и вернуться к добавлению новых записей


Добавление нового сайта открывает специальный диалог, в котором вы задаете его отображаемое имя, URL и режим сопоставления; сохранение нового сайта сразу же повторно открывает главный диалог настроек для этого сайта, чтобы вы могли сразу начать добавление записей.

Импорт записей из файла


Вы можете массово загружать записи в текущий выбранный сайт с помощью функции Импортировать из файла.... Browsers Dictionary читает JSON-файл, содержащий список "words", где каждая запись может быть простой строкой (рассматриваемой как простая замена текста) или полным объектом с настройками шаблона, замены и регулярного выражения. После подтверждения программа сообщает, сколько записей было добавлено и сколько пропущено, например, потому что они уже существовали для этого сайта.

Предупреждения безопасности регулярных выражений и временной бюджет


Для защиты от шаблонов, которые могут привести к зависанию или замедлению речи:


- Когда вы сохраняете регулярное выражение, которое выглядит так, будто оно может вызвать неконтролируемый «катастрофический возврат» (определенные вложенные повторяющиеся группы), NVDA предупреждает вас, что шаблон может работать медленно, чтобы вы могли его упростить. Это полезное предупреждение, а не жесткая блокировка; запись все равно сохраняется
- Во время непосредственного произнесения речи Browsers Dictionary выделяет лишь краткое общее время обработки для всех записей регулярных выражений на отдельном фрагменте речи. Если этот бюджет исчерпан, любые оставшиеся записи regex для этого фрагмента речи пропускаются, чтобы ваша речь не задерживалась
- Экстремально длинные текстовые фрагменты вообще не сканируются на предмет замен, так как их сканирование добавило бы задержки без заметной пользы

Плавная миграция со старых конфигураций


Browsers Dictionary автоматически проверяет наличие данных конфигурации, оставленных более ранними версиями или предыдущим названием дополнения «Invisible», и объединяет их в текущую конфигурацию при первом запуске. Сайты и записи из старого макета копируются без перезаписи того, что вы уже настроили; если файл с тем же именем уже существует, старая копия сохраняется как резервная копия вместо удаления. Дублирующиеся файлы сайтов, представляющие один и тот же сайт, автоматически объединяются, а дублирующиеся записи комбинируются в один список.

Browsers Dictionary


Ваш собственный речевой словарь для каждого веб-сайта — слушайте страницы так, как вы хотите.


Автор: chai chaimee

URL: https://github.com/chaichaimee/BrowsersDictionary


Введение


Browsers Dictionary позволяет создавать собственный речевой словарь для конкретного веб-сайта в NVDA. В отличие от встроенного речевого словаря NVDA, который применяется повсеместно, это дополнение позволяет привязывать замены слов и фраз только к определенным сайтам — поэтому правило, созданное для одного сайта, никогда не будет применяться к другому сайту или какому-либо другому приложению.


Вы можете переименовывать непонятные метки, сокращать длинный или повторяющийся текст или заставлять молчать фразы, которые вы никогда не хотите слышать, и все это ограничено только той страницей или сайтом, где они вам мешают. Правила применяются в реальном времени при просмотре страниц и могут быть созданы как на основе точного совпадения текста, так и на основе регулярных выражений.


Поддерживаемые браузеры: Firefox, Chrome, Microsoft Edge, Brave, Opera и Internet Explorer.


Это дополнение работает полностью в автономном режиме (офлайн). Оно не отправляет и не получает никаких данных по сети — все словари хранятся локально на вашем компьютере.

Горячие клавиши


Alt+Windows+B
Одиночное нажатие : Открыть настройки Browsers Dictionary для текущего сайта
Двойное нажатие : Добавить текущую страницу как новый сайт
Тройное нажатие : Редактировать существующую конфигурацию текущего сайта

Как работает многократное нажатие: Нажмите комбинацию клавиш один, два или три раза подряд в быстром темпе (в течение доли секунды друг за другом). Чуть более долгая пауза между нажатиями сбрасывает счетчик, поэтому одиночное медленное нажатие всегда воспринимается как однократное.

Одиночное нажатие всегда открывает главный диалог настроек, показывая сайт, соответствующий вашей текущей странице, если он уже настроен, или готовую к заполнению новую запись, если нет.

Двойное нажатие — это горячая клавиша для быстрой регистрации страницы, на которой вы сейчас находитесь, в качестве нового сайта. Для этого требуется, чтобы NVDA сначала успешно захватила URL-адрес страницы; если это не удалось, вы услышите сообщение с просьбой убедиться, что вы находитесь в браузере.

Тройное нажатие переходит непосредственно к редактированию сайта, уже настроенного для вашей текущей страницы. Если для этой страницы еще не настроен сайт, вам будет предложено сначала сделать двойное нажатие, чтобы добавить его.

Возможности


Речевые словари для конкретных сайтов


Каждый добавляемый вами сайт получает свой собственный независимый список записей слов/фраз. Запись может быть:


Заменой обычным текстом — любое точное совпадение с шаблоном заменяется вашим текстом замены.
Заменой регулярным выражением — для более гибкого поиска на основе шаблонов.


Оставление поля замены пустым является правильным и осознанным выбором — это означает "ничего не произносить" для этого шаблона, точно так же, как если оставить замену пустой во встроенном речевом словаре NVDA.


Пример: На сайте, где кнопка чата озвучивается как "btn_send_msg_42", вы можете добавить обычную текстовую запись, заменяющую ее на "Отправить".

Три способа сопоставления сайта


При добавлении или редактировании сайта вы выбираете, как его адрес сравнивается со страницей, на которой вы находитесь:


Только отдельная страница — словарь применяется только при точном совпадении URL-адреса. Лучше всего подходит для страницы, адрес которой никогда не меняется.
Весь веб-сайт (домен) — словарь применяется в любом месте одного и того же домена, независимо от остальной части адреса. Это вариант по умолчанию и рекомендуемый выбор, поскольку большинство сайтов используют уникальные адреса для каждой страницы или сессии.
Регулярное выражение — словарь применяется к любому URL-адресу, который совпадает с вашим шаблоном с самого начала. Полезно для сайтов с предсказуемой структурой URL-адресов, которые вы хотите точно указать.

Автоматическое определение текущего сайта


Browsers Dictionary отслеживает адрес страницы, которую вы сейчас просматриваете, в фоновом режиме, поэтому он всегда знает, словарь какого сайта (если таковой имеется) должен применяться. Это отслеживание обновляется:


- При переключении в окно браузера.
- При перемещении фокуса внутри страницы (проверяется не чаще двух раз в секунду, чтобы избежать избыточной нагрузки).
- В момент завершения загрузки новой страницы.


Вам никогда не нужно ничего делать для вызова этого процесса — он происходит автоматически во время просмотра страниц.

Сопоставление через разделенные фрагменты речи


NVDA иногда произносит одну строку как несколько отдельных фрагментов речи — например, роль ссылки, сам текст ссылки и текст, следующий за ней. Browsers Dictionary предназначен для перехвата шаблонов, охватывающих именно такие границы, так что фраза вроде "сообщений до ..." все равно может быть найдена и заменена, даже если "сообщений" является текстом ссылки, а остальное следует сразу за ним.


Очень длинные произносимые фрагменты (более 20 000 символов) полностью пропускаются при сканировании, поскольку поиск шаблонов в таких больших блоках создает заметную задержку без какой-либо реальной пользы.

Проверки безопасности регулярных выражений


Каждый раз при сохранении регулярного выражения — будь то для записи слова или для шаблона URL-адреса самого сайта — Browsers Dictionary проверяет его двумя способами:


Шаг 1 — Проверка валидности: шаблон должен успешно компилироваться как корректное регулярное выражение, иначе в сохранении будет отказано с объяснением причины.
Шаг 2 — Проверка на зависание шаблона: шаблон сравнивается с известной структурой, которая часто приводит к крайне медленной работе регулярных выражений на определенном тексте (повторяющиеся вложенные группы, такие как (x+)+). Если он соответствует этой структуре, вы услышите предупреждающее сообщение — но шаблон все равно будет сохранен, поскольку эта проверка не может гарантировать, что шаблон действительно небезопасен, а только то, что он похож на небезопасные.


В качестве дополнительной защиты во время просмотра страниц все записи слов с регулярными выражениями для одной произносимой фразы используют общий лимит времени в 0,1 секунды. Если этот лимит исчерпан, все оставшиеся записи с регулярными выражениями для этой фразы пропускаются для данного случая, поэтому один тяжелый шаблон не может заметно замедлить синтез речи.

Управление сайтами и записями


В диалоге настроек с одной стороны перейдены все ваши настроенные сайты, а с другой — записи словаря текущего сайта. Отсюда вы можете:


- Добавлять, редактировать или удалять запись словаря (также доступно с помощью клавиши Delete или контекстного меню по правому клику в списке записей).
- Редактировать или удалять весь сайт (также доступно с помощью клавиши Delete или контекстного меню по правому клику в списке сайтов).
- Импортировать список записей из файла JSON непосредственно в выбранный в данный момент сайт.

Импорт записей из файла


Вы можете массово загружать записи словаря в выбранный в данный момент сайт из файла JSON. Файл должен содержать список "words", содержащий либо простые текстовые значения, либо более полные записи с шаблоном, необязательным флагом регулярного выражения и необязательной заменой.


Записи с ошибками структуры пропускаются, а не останавливают весь импорт, и по завершении вам будет точно сообщено, сколько записей было добавлено, а сколько пропущено. Импортированные регулярные выражения проходят те же проверки валидности и проверки на зависание, что описаны выше.

Автоматическая миграция конфигурации


Если Browsers Dictionary обнаруживает словари, сохраненные более старой версией дополнения (включая версию, выпущенную под прежним названием этого дополнения), он автоматически копирует их в текущее местоположение конфигурации при первом запуске. Ничего не теряется, даже если записи уже существуют в обоих местах — у совпадающих сайтов их списки слов объединяются, а не перезаписываются один другим.

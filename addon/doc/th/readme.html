Browsers Dictionary

บทนำ


Browsers Dictionary ช่วยให้คุณสร้าง พจนานุกรมการอ่านออกเสียงแยกตามเว็บไซต์ ของคุณเองสำหรับ NVDA ได้ ต่างจากพจนานุกรมการอ่านออกเสียงในตัวของ NVDA ที่มีผลบังคับใช้กับทุกสถานที่ แอพพลายนี้ช่วยให้คุณกำหนดการแทนที่คำและวลีให้มีผลเฉพาะกับไซต์ที่กำหนดเท่านั้น — ดังนั้นกฎที่คุณสร้างขึ้นสำหรับเว็บหนึ่งจะไม่ส่งผลกระทบไปข้ามยังเว็บไซต์อื่น หรือโปรแกรมอื่นใดเลย


คุณสามารถเปลี่ยนชื่อป้ายกำกับที่สับสน ย่อข้อความที่ยาวหรือซ้ำซ้อน หรือสั่งปิดเสียงวลีที่คุณไม่อยากฟังเลย โดยทั้งหมดนี้จะถูกจำกัดขอบเขตอยู่เฉพาะหน้าเว็บหรือเว็บไซต์ที่มีปัญหาเท่านั้น กฎจะมีผลทำงานแบบเรียลไทม์ขณะที่คุณท่องเว็บ และสามารถสร้างขึ้นได้ทั้งจากการจับคู่ข้อความธรรมดาหรือนิพจน์เรกิวลาร์ (Regular Expression)


เบราว์เซอร์ที่รองรับ: Firefox, Chrome, Microsoft Edge, Brave, Opera และ Internet Explorer


แอพพลายนี้ทำงานแบบออฟไลน์ทั้งหมด ไม่มีการส่งหรือดึงข้อมูลใดๆ ผ่านเครือข่าย — พจนานุกรมทั้งหมดจะถูกจัดเก็บไว้ในเครื่องคอมพิวเตอร์ของคุณเท่านั้น

ปุ่มลัด


Alt+Windows+B
กดครั้งเดียว : เปิดการตั้งค่า Browsers Dictionary สำหรับเว็บไซต์ปัจจุบัน
กดสองครั้ง : เพิ่มหน้าปัจจุบันเป็นเว็บไซต์ใหม่
กดสามครั้ง : แก้ไขการตั้งค่าที่มีอยู่ของเว็บไซต์ปัจจุบัน

หลักการทำงานของการกดปุ่ม: กดปุ่มลัดชุดนี้ ติดต่อกันหนึ่ง สอง หรือสามครั้งอย่างรวดเร็ว (ภายในเสี้ยววินาทีของแต่ละครั้ง) หากเว้นช่วงนานขึ้นเล็กน้อยระหว่างการกดจะถือเป็นการเริ่มนับใหม่ ดังนั้นการกดช้าๆ เพียงครั้งเดียวจะถูกจัดการเป็นการกดครั้งเดียวเสมอ

การกดครั้งเดียว จะเปิดหน้าต่างการตั้งค่าหลักเสมอ โดยแสดงเว็บไซต์ที่ตรงกับหน้าปัจจุบันของคุณหากได้รับการตั้งค่าไว้แล้ว หรือแสดงรายการใหม่พร้อมให้กรอกหากยังไม่มี

การกดสองครั้ง เป็นทางลัดในการลงทะเบียนหน้าเว็บที่คุณกำลังเปิดอยู่ให้เป็นเว็บไซต์ใหม่ได้อย่างรวดเร็ว โดยจำเป็นต้องให้ NVDA ดึง URL ของหน้าเว็บมาได้สำเร็จก่อน หากยังดึงไม่ได้ คุณจะได้ยินข้อความแจ้งเตือนให้แน่ใจว่าคุณกำลังอยู่ในเบราว์เซอร์

การกดสามครั้ง จะข้ามไปยังการแก้ไขเว็บไซต์ที่ตั้งค่าไว้แล้วสำหรับหน้าปัจจุบันของคุณโดยตรง หากยังไม่มีการตั้งค่าเว็บไซต์สำหรับหน้านั้น คุณจะได้รับการแจ้งเตือนให้กดสองครั้งก่อนเพื่อทำการเพิ่ม

คุณสมบัติ


พจนานุกรมการอ่านออกเสียงแยกตามไซต์


แต่ละไซต์ที่คุณเพิ่มจะมีรายการคำ/วลีที่เป็นอิสระของตัวเอง โดยรายการสามารถเป็นได้ทั้ง:


การแทนที่ข้อความธรรมดา — ทุกคำที่ตรงกับรูปแบบที่กำหนดอย่างถูกต้องจะถูกสลับเป็นข้อความแทนที่คุณตั้งไว้
การแทนที่ด้วยนิพจน์เรกิวลาร์ (Regular Expression) — สำหรับการจับคู่ตามรูปแบบที่มีความยืดหยุ่นมากขึ้น


การเว้นช่องแทนที่ให้ว่างไว้เป็นการตั้งใจและเป็นตัวเลือกที่ถูกต้อง — หมายถึง "ไม่อ่านออกเสียงใดๆ" สำหรับรูปแบบนั้น เช่นเดียวกับการเว้นช่องแทนที่ให้ว่างในพจนานุกรมการอ่านออกเสียงในตัวของ NVDA


ตัวอย่าง: บนไซต์ที่มีปุ่มแชทอ่านออกเสียงว่า "btn_send_msg_42" คุณสามารถเพิ่มรายการข้อความธรรมดาเพื่อแทนที่ด้วยคำว่า "ส่ง" ได้

สามวิธีในการจับคู่เว็บไซต์


เมื่อเพิ่มหรือแก้ไขเว็บไซต์ คุณสามารถเลือกได้ว่าจะให้เปรียบเทียบที่อยู่เว็บกับหน้าที่คุณเปิดูอย่างไร:


เฉพาะหน้าเดียวเท่านั้น — พจนานุกรมจะมีผลเฉพาะเมื่อ URL ตรงกันเป๊ะๆ เหมาะสำหรับหน้าเว็บที่ที่อยู่ไม่มีวันเปลี่ยน
ทั้งเว็บไซต์ (โดเมน) — พจนานุกรมจะมีผลทุกที่ภายใต้โดเมนเดียวกัน โดยไม่สนใจส่วนที่เหลือของที่อยู่เว็บ นี่เป็นตัวเลือกเริ่มต้นและเป็นตัวเลือกที่แนะนำ เนื่องจากไซต์ส่วนใหญ่มักใช้ที่อยู่เว็บที่เปลี่ยนไปตามหน้าหรือตามเซสชัน
นิพจน์เรกิวลาร์ — พจนานุกรมจะมีผลกับ URL ใดก็ตามที่ตรงกับรูปแบบของคุณตั้งแต่เริ่มต้น มีประโยชน์สำหรับไซต์ที่มีโครงสร้าง URL ที่คาดเดาได้ที่คุณต้องการกำหนดเป้าหมายอย่างแม่นยำ

ระบบตรวจจับไซต์ปัจจุบันอัตโนมัติ


Browsers Dictionary จะติดตามที่อยู่ของหน้าเว็บที่คุณกำลังดูอยู่เบื้องหลังเสมอ เพื่อให้ทราบตลอดเวลาว่าควรใช้พจนานุกรมของไซต์ใด (หากมี) การติดตามนี้จะอัปเดต:


- เมื่อคุณสลับไปยังหน้าต่างเบราว์เซอร์
- เมื่อโฟกัสย้ายตำแหน่งภายในหน้าเว็บ (ตรวจสอบไม่เกินสองครั้งต่อวินาที เพื่อหลีกเลี่ยงการทำงานที่เกินจำเป็น)
- ทันทีที่หน้าเว็บใหม่โหลดเสร็จสิ้น


คุณไม่ต้องทำอะไรเลยเพื่อเปิดใช้งานสิ่งนี้ — ระบบจะทำงานโดยอัตโนมัติขณะที่คุณท่องเว็บ

การจับคู่ข้ามส่วนคำพูดที่ถูกแยก


บางครั้ง NVDA จะอ่านออกเสียงบรรทัดเดียวเป็นส่วนๆ แยกกัน — เช่น ชนิดของลิงก์, ข้อความตัวลิงก์เอง, และข้อความที่ตามหลัง Browsers Dictionary ถูกออกแบบมาให้จับรูปแบบที่คาบเกี่ยวข้ามขอบเขตประเภทนี้ได้ ดังนั้นวลีเช่น "messages until ..." จึงยังคงถูกจับคู่และแทนที่ได้ แม้คำว่า "messages" จะเป็นข้อความลิงก์และส่วนที่เหลือจะตามมาทันทีก็ตาม


ข้อความอ่านออกเสียงที่ยาวมากๆ (เกิน 20,000 ตัวอักษร) จะถูกข้ามจากการสแกนโดยสิ้นเชิง เนื่องจาก การค้นหารูปแบบในข้อความขนาดใหญ่เช่นนั้นจะเพิ่มภาระอย่างเห็นได้ชัดโดยแทบไม่มีประโยชน์จริง

การตรวจสอบความปลอดภัยของนิพจน์เรกิวลาร์


เมื่อใดก็ตามที่คุณบันทึกนิพจน์เรกิวลาร์ — ไม่ว่าจะเป็นสำหรับรายการคำ หรือรูปแบบ URL ของเว็บไซต์ — Browsers Dictionary จะตรวจสอบในสองขั้นตอน:


ขั้นตอนที่ 1 — การตรวจสอบความถูกต้อง: รูปแบบต้องประมวลผลเป็นนิพจน์เรกิวลาร์ที่ถูกต้อง มิฉะนั้นจะปฏิเสธการบันทึกพร้อมอธิบายเหตุผล
ขั้นตอนที่ 2 — การตรวจสอบรูปแบบที่อาจทำงานวนลูปไม่จบ: รูปแบบจะถูกเปรียบเทียบกับ "โครงสร้าง" ที่เป็นที่รู้จักซึ่งมักเป็นสาเหตุให้นิพจน์เรกิวลาร์ทำงานช้ามากบนข้อความบางประเภท (กลุ่มซ้อนกันที่ทำซ้ำ เช่น (x+)+) หากตรงกับโครงสร้างนี้ คุณจะได้ยินข้อความเตือน — แต่รูปแบบจะยังคงถูกบันทึก เนื่องจาก การตรวจสอบนี้ไม่สามารถรับประกันได้ว่ารูปแบบนั้นไม่ปลอดภัยจริงหรือไม่ เพียงแค่ระบุว่ามันคล้ายกับรูปแบบที่มีความเสี่ยง


เพื่อเป็นมาตรการป้องกันเพิ่มเติมขณะคุณท่องเว็บ รายการคำนิพจน์เรกิวลาร์ทั้งหมดสำหรับวลีอ่านออกเสียงเดียวจะแชร์โควตาเวลารวมกันที่ 0.1 วินาที หากเวลานี้หมดลง รายการนิพจน์เรกิวลาร์ที่เหลือสำหรับวลีนั้นจะถูกข้ามไปสำหรับการอ่านครั้งนั้น เพื่อไม่ให้รูปแบบที่ประมวลผลหนักส่งผลให้เสียงอ่านล่าช้าอย่างเห็นได้ชัด

การจัดการเว็บไซต์และรายการ


หน้าต่างการตั้งค่าจะแสดงรายการเว็บไซต์ทั้งหมดที่คุณตั้งค่าไว้ด้านหนึ่ง และรายการพจนานุกรมของเว็บไซต์ปัจจุบันอีกด้านหนึ่ง จากจุดนี้คุณสามารถ:


- เพิ่ม, แก้ไข หรือลบรายการพจนานุกรม (สามารถเข้าถึงได้ผ่านปุ่ม Delete หรือเมนูคลิกขวาบนรายการคำด้วย)
- แก้ไข หรือลบเว็บไซต์ทั้งหมด (สามารถเข้าถึงได้ผ่านปุ่ม Delete หรือเมนูคลิกขวาบนรายการเว็บไซต์ด้วย)
- นำเข้าความหมายรายการจากไฟล์ JSON เข้าสู่เว็บไซต์ที่เลือกอยู่โดยตรง

การนำเข้าความหมายรายการจากไฟล์


คุณสามารถโหลดรายการพจนานุกรมจำนวนมากเข้าสู่เว็บไซต์ที่เลือกอยู่ได้จากไฟล์ JSON โดยไฟล์จำเป็นต้องมีรายการ "words" ที่บรรจุค่าข้อความธรรมดา หรือรายการแบบสมบูรณ์ที่มีรูปแบบ (pattern), ตัวเลือก regex, และคำแทนที่


รายการที่รูปแบบไม่ถูกต้องจะถูกข้ามแทนที่จะยกเลิกการนำเข้าทั้งหมด และจะมีการแจ้งให้ทราบอย่างแม่นยำว่ามีกี่รายการที่เพิ่มสำเร็จและกี่รายการที่ถูกข้ามเมื่อกระบวนการเสร็จสิ้น นิพจน์เรกิวลาร์ที่นำเข้าจะผ่านการตรวจสอบความถูกต้องและการตรวจสอบรูปแบบที่อาจทำงานวนลูปตามที่อธิบายไว้ข้างต้นเช่นกัน

การย้ายข้อมูลการตั้งค่าอัตโนมัติ


หาก Browsers Dictionary ตรวจพบพจนานุกรมที่บันทึกไว้โดยแอพพลายเวอร์ชันเก่า (รวมถึงเวอร์ชันที่ปล่อยภายใต้ชื่อเดิมของแอพพลายนี้) ระบบจะคัดลอกข้อมูลเหล่านั้นไปยังตำแหน่งการตั้งค่าปัจจุบันโดยอัตโนมัติเมื่อเปิดใช้งานครั้งแรก จะไม่มีข้อมูลใดสูญหายแม้ว่าจะมีรายการอยู่น่าทั้งสองแห่งแล้ว — ไซต์ที่ตรงกันจะถูกนำรายการคำมารวมเข้าด้วยกัน แทนที่จะให้อันใดอันหนึ่งเขียนทับอีกอัน



สนับสนุนผู้พัฒนา

หากเครื่องมือนี้ช่วยให้ชีวิตของคุณสะดวกสบายยิ่งขึ้น สามารถร่วมสนับสนุนการอัปเดตครั้งถัดไปได้ผ่านการบริจาคเล็กๆ น้อยๆ



ทุกการสนับสนุนของคุณมีความหมายอย่างยิ่ง มาร่วมสร้างสรรค์สิ่งดีๆ ไปด้วยกัน

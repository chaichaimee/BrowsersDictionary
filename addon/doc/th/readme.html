Browsers Dictionary


พจนานุกรมการออกเสียงส่วนบุคคลของคุณสำหรับทุกเว็บไซต์ ออกเสียงได้อย่างแม่นยำในแบบที่คุณต้องการ


author: chai chaimee

บทนำ


Browsers Dictionary ช่วยให้คุณสร้าง "พจนานุกรมการออกเสียง" แบบกำหนดเองสำหรับแต่ละเว็บไซต์สำหรับการอ่านออกเสียงของ NVDA หากเว็บไซต์มีการใช้คำ ตัวย่อ หรือศัพท์เฉพาะที่ NVDA อ่านออกเสียงได้ไม่ราบรื่น คุณสามารถกำหนดรูปแบบข้อความหรือนิพจน์ทั่วไป (Regular expression) พร้อมคำแทนที่ และ NVDA จะออกเสียงคำแทนที่นั้นทุกครั้งที่รูปแบบดังกล่าวปรากฏบนหน้านั้นโดยเฉพาะ บนเว็บไซต์นั้นทั้งหมด หรือบน URL ใดๆ ที่ตรงกับรูปแบบที่คุณกำหนด


ส่วนเสริมนี้จะทำงานโดยอัตโนมัติเมื่อตั้งค่าเสร็จ: คอยตรวจสอบอย่างเงียบ ๆ ว่าแท็บเบราว์เซอร์หรือหน้าใดกำลังใช้งานอยู่ และเขียนทับเสียงพูดที่ NVDA กำลังจะพูดแบบเรียลไทม์ ตามกฎที่คุณกำหนดไว้สำหรับเว็บไซต์ปัจจุบัน


กำลังอัปเกรดจาก Invisible หรือไม่?
Browsers Dictionary เป็นเวอร์ชันปรับปรุงของส่วนเสริม "Invisible" หากคุณติดตั้ง Invisible อยู่ในขณะนี้ เพียงแค่ถอนการติดตั้งออกก่อน จากนั้นติดตั้ง Browsers Dictionary แล้วใช้งานต่อได้ทันที คุณไม่ต้องตั้งค่าเว็บไซต์ใหม่ใดๆ: การตั้งค่าเว็บไซต์ทั้งหมดที่คุณเคยกำหนดไว้ใน Invisible จะถูกโอนย้ายไปยัง Browsers Dictionary โดยอัตโนมัติในการรันครั้งแรก

ปุ่มลัด


NVDA+Shift+W
แตะครั้งเดียว : เปิดการตั้งค่า Browsers Dictionary สำหรับเว็บไซต์ปัจจุบัน
แตะสองครั้ง : บันทึก URL ของหน้าปัจจุบันและเปิดกล่องโต้ตอบเพิ่มเว็บไซต์ใหม่

แตะหนึ่งครั้งเพื่อตรวจสอบหรือแก้ไขรายการพจนานุกรมที่บันทึกไว้สำหรับหน้าที่คุณกำลังใช้งานอยู่ แตะสองครั้งอย่างรวดเร็วในขณะที่โฟกัสอยู่ในเบราว์เซอร์เพื่อสร้างรายการเว็บไซต์ใหม่ทันทีโดยใช้ URL ของหน้าที่คุณกำลังดูอยู่ หาก NVDA ไม่สามารถตรวจจับ URL สำหรับการแตะสองครั้งได้ (เช่น คุณไม่ได้อยู่ในเบราว์เซอร์ที่รองรับ) ระบบจะแจ้งว่า "ไม่สามารถบันทึก URL ได้ โปรดตรวจสอบให้แน่ใจว่าคุณอยู่ในเบราว์เซอร์"

คุณสมบัติ


การติดตาม URL แบบสดโดยอัตโนมัติ


Browsers Dictionary จะติดตามหน้าที่คุณอยู่โดยที่คุณไม่ต้องทำอะไรเลย ระบบจะอัปเดตบันทึก URL ปัจจุบัน:


- เมื่อคุณสลับไปยังหน้าต่างเบราว์เซอร์ (Firefox, Chrome, Edge, Brave, Opera หรือ Internet Explorer)
- เมื่อหน้าเว็บโหลดเสร็จสิ้น
- เมื่อโฟกัสย้ายไปยังองค์ประกอบใหม่ อย่างน้อยที่สุดสองครั้งต่อวินาที เพื่อให้เป็นปัจจุบันโดยไม่ทำให้เบราว์เซอร์ทำงานหนักเกินไป


URL นี้คือสิ่งที่ส่วนเสริมใช้เบื้องหลังเพื่อตัดสินว่าชุดรายการพจนานุกรมใดควรใช้กับสิ่งที่คุณกำลังอ่านอยู่

การแทนที่คำและรูปแบบแยกตามเว็บไซต์


สำหรับแต่ละเว็บไซต์ที่คุณเพิ่ม คุณสามารถสร้างรายการรายการต่างๆ ได้ แต่ละรายการประกอบด้วย:


- รูปแบบ (Pattern): ข้อความที่แน่นอน หรือนิพจน์ทั่วไป (Regular expression) ที่ต้องการค้นหา
- คำแทนที่ (Replacement) (ไม่บังคับ): สิ่งที่ NVDA ควรอุดเสียงแทน หากปล่อยว่างไว้ ข้อความที่ตรงกันจะถูกลบออกจากการพูดทันที
- ช่องทำเครื่องหมาย ใช้เป็นนิพจน์ทั่วไป (Use as regular expression) สำหรับการจับคู่รูปแบบขั้นสูง


เมื่อใดก็ตามที่ NVDA กำลังจะพูดข้อความบนหน้าที่ตรงกัน Browsers Dictionary จะตรวจสอบเทียบกับรายการของคุณและแทนที่ข้อความที่ตรงกันก่อนที่จะเปล่งเสียงพูด รายการที่เป็นข้อความธรรมดาจะถูกตรวจสอบก่อน (รายการที่ยาวที่สุดมาก่อน เพื่อหลีกเลี่ยงการทับซ้อนบางส่วน) ตามด้วยนิพจน์ทั่วไปของคุณ

สามวิธีในการจับคู่เว็บไซต์


เมื่อเพิ่มหรือแก้ไขเว็บไซต์ คุณสามารถเลือกขอบเขตการใช้งานรายการพจนานุกรมได้:


หน้าเดียวเท่านั้น: รายการจะมีผลเฉพาะกับ URL ที่แน่นอนที่คุณบันทึกไว้เท่านั้น
เว็บไซต์ทั้งหมด (โดเมน): รายการจะมีผลกับทุกหน้าบนโดเมนเดียวกัน โดยไม่คำนึงถึงเส้นทางเฉพาะ
นิพจน์ทั่วไป: รายการจะมีผลกับ URL ใดๆ ที่ตรงกับรูปแบบที่คุณเขียน โดยตรวจสอบตั้งแต่เริ่มต้นที่อยู่

การจัดการเว็บไซต์และรายการ


กล่องโต้ตอบการตั้งค่า (เปิดด้วยการแตะครั้งเดียวของ NVDA+Shift+W) ประกอบด้วยรายชื่อเว็บไซต์ และสำหรับเว็บไซต์ที่เลือก จะมีรายชื่อรายการ จากที่นี่คุณสามารถ:


- เพิ่ม, แก้ไข หรือ ลบ รายการคำหรือรูปแบบ พร้อมการยืนยันก่อนลบ
- เปิดเมนูบริบท (หรือกดปุ่ม Delete) บนเว็บไซต์หรือรายการเพื่อดำเนินการแก้ไข/ลบอย่างรวดเร็ว
- แก้ไขเว็บไซต์ หรือ ลบเว็บไซต์ ได้โดยตรงจากเมนูบริบทของรายชื่อเว็บไซต์
- ยกเลิกการแก้ไขที่กำลังดำเนินการและกลับไปเพิ่มรายการใหม่


การเพิ่มเว็บไซต์ใหม่จะเปิดกล่องโต้ตอบเฉพาะที่คุณกำหนดชื่อที่แสดง URL และโหมดการจับคู่ การบันทึกเว็บไซต์ใหม่จะเปิดกล่องโต้ตอบการตั้งค่าหลักสำหรับเว็บไซต์นั้นทันทีเพื่อให้คุณเริ่มเพิ่มรายการได้ทันที

นำเข้ารายการจากไฟล์


คุณสามารถโหลดรายการจำนวนมากไปยังเว็บไซต์ที่เลือกในปัจจุบันโดยใช้ นำเข้าจากไฟล์... Browsers Dictionary จะอ่านไฟล์ JSON ที่มีรายการ "words" ซึ่งแต่ละรายการสามารถเป็นสตริงธรรมดา (ถือเป็นการแทนที่ข้อความธรรมดา) หรือออบเจ็กต์เต็มรูปแบบที่มีการตั้งค่ารูปแบบ การแทนที่ และเรเก็กซ์ หลังจากที่คุณยืนยัน ระบบจะรายงานว่ามีรายการถูกเพิ่มกี่รายการและถูกข้ามกี่รายการ เช่น เนื่องจากมีอยู่แล้วสำหรับเว็บไซต์นั้น

คำเตือนความปลอดภัยของ Regex และงบประมาณเวลา


เพื่อปกป้องคุณจากรูปแบบที่อาจทำให้เสียงพูดค้างหรือช้าลง:


- เมื่อคุณบันทึกนิพจน์ทั่วไปที่มีลักษณะอาจทำให้เกิด "การวนซ้ำแบบถอยหลังที่ผิดพลาดรุนแรง" (catastrophic backtracking) (กลุ่มซ้อนทับที่มีการทำซ้ำบางกลุ่ม) NVDA จะเตือนคุณว่ารูปแบบดังกล่าวอาจทำงานช้า เพื่อให้คุณสามารถทำให้ง่ายขึ้นได้ นี่คือคำเตือนที่มีประโยชน์ ไม่ใช่การบล็อกอย่างเด็ดขาด รายการยังคงถูกบันทึกไว้
- ระหว่างการพูดจริง Browsers Dictionary จะอนุญาตให้มีเวลาประมวลผลรวมสั้นๆ สำหรับรายการนิพจน์ทั่วไปทั้งหมดบนข้อความพูดหนึ่งชิ้น หากงบประมาณนั้นหมดลง รายการ regex ที่เหลือสำหรับข้อความชิ้นนั้นจะถูกข้ามเพื่อให้เสียงพูดของคุณไม่สะดุด
- ส่วนข้อความที่ยาวมากๆ จะไม่ถูกสแกนหาการแทนที่เลย เนื่องจากหากสแกนจะเพิ่มความล่าช้าโดยไม่มีประโยชน์ที่มีนัยสำคัญ

การย้ายข้อมูลอย่างไร้รอยต่อจากการกำหนดค่ารุ่นเก่า


Browsers Dictionary จะตรวจสอบข้อมูลการกำหนดค่าที่หลงเหลือจากเวอร์ชันก่อนหน้าหรือชื่อส่วนเสริม "Invisible" เดิมโดยอัตโนมัติ และรวมเข้ากับการกำหนดค่าปัจจุบันในการรันครั้งแรก เว็บไซต์และรายการจากเค้าโครงรุ่นเก่าจะถูกคัดลอกเข้ามาโดยไม่เขียนทับสิ่งที่คุณตั้งค่าไว้แล้ว หากมีไฟล์ชื่อเดียวกันอยู่แล้ว สำเนาเก่าจะถูกเก็บไว้เป็นข้อมูลสำรองแทนที่จะถูกลบ ไฟล์เว็บไซต์ที่ซ้ำกันซึ่งแสดงถึงเว็บไซต์เดียวกันจะถูกรวมเข้าด้วยกันโดยอัตโนมัติ โดยรวมรายการที่ซ้ำกันเป็นรายการเดียว



สนับสนุนฉัน

หากเครื่องมือนี้ทำให้ชีวิตของคุณง่ายขึ้น ลองสนับสนุนการอัปเดตครั้งต่อไปด้วยการบริจาคเล็กๆ น้อยๆ



การสนับสนุนของคุณมีความหมายอย่างมาก มาสร้างสรรค์สิ่งดีๆ ร่วมกัน

Browsers Dictionary


Tu propio diccionario de pronunciación para cada sitio web — escucha las páginas como tú quieras.


Autor: chai chaimee

Introducción


Browsers Dictionary te permite crear tu propio diccionario de habla por sitio web para NVDA. A diferencia del diccionario de habla integrado de NVDA, que se aplica en todas partes, este complemento te permite vincular sustituciones de palabras y frases solo a sitios específicos — por lo que una regla que crees para un sitio web nunca se aplicará a otro sitio web ni a ninguna otra aplicación.


Puedes renombrar etiquetas confusas, acortar texto largo o repetitivo, o silenciar frases que nunca quieras escuchar habladas, todo limitado únicamente a la página o sitio donde te molesten. Las reglas se aplican en tiempo real mientras navegas y se pueden crear tanto a partir de coincidencias de texto plano como de expresiones regulares.


Navegadores compatibles: Firefox, Chrome, Microsoft Edge, Brave, Opera e Internet Explorer.


Este complemento funciona completamente fuera de línea. No envía ni recupera datos a través de la red — todos los diccionarios se almacenan localmente en tu ordenador.

Teclas de acceso rápido


Alt+Windows+B
Un toque : Abrir las Opciones de Browsers Dictionary para el sitio actual
Doble toque : Añadir la página actual como un nuevo sitio
Triple toque : Editar la configuración existente del sitio actual

Cómo funciona el pulsado repetido: Pulsa la combinación de teclas una, dos o tres veces en rápida sucesión (dentro de una fracción de segundo entre cada pulsación). Esperar un poco más entre pulsaciones reinicia la cuenta, por lo que una sola pulsación lenta siempre se trata como un toque simple.

Un toque siempre abre el diálogo principal de Opciones, mostrando el sitio que coincide con tu página actual si ya hay uno configurado, o una nueva entrada lista para rellenar si no es así.

Doble toque es un atajo para registrar rápidamente la página en la que te encuentras actualmente como un nuevo sitio. Requiere que NVDA haya capturado previamente con éxito la URL de la página; si no lo ha hecho, escucharás un mensaje pidiéndote que te asegures de estar en un navegador.

Triple toque salta directamente a editar el sitio ya configurado para tu página actual. Si aún no hay un sitio configurado para esa página, se te indicará que hagas un doble toque primero para añadir uno.

Características


Diccionarios de habla por sitio


Cada sitio que añades obtiene su propia lista independiente de entradas de palabras/frases. Una entrada puede ser:


Un reemplazo de texto plano — cualquier ocurrencia exacta del patrón se sustituye por tu texto de reemplazo.
Un reemplazo de expresión regular — para coincidencias más flexibles basadas en patrones.


Dejar el campo de reemplazo en blanco es una opción válida y deliberada — significa "no decir nada" para ese patrón, exactamente igual que dejar un reemplazo en blanco en el propio diccionario de habla integrado de NVDA.


Ejemplo: En un sitio donde un botón de chat se anuncia como "btn_send_msg_42", podrías añadir una entrada de texto plano reemplazándolo por "Enviar".

Tres formas de coincidir con un sitio


Al añadir o editar un sitio, eliges cómo se compara su dirección con la página en la que te encuentras:


Solo página individual — el diccionario se aplica solo cuando la URL coincide exactamente. Ideal para una página cuya dirección nunca cambia.
Sitio web completo (dominio) — el diccionario se aplica en cualquier lugar del mismo dominio, independientemente del resto de la dirección. Esta es la opción predeterminada y recomendada, ya que la mayoría de los sitios usan direcciones únicas por página o por sesión.
Expresión regular — el diccionario se aplica a cualquier URL que coincida con tu patrón desde el principio. Útil para sitios con una estructura de URL predecible que desees definir con precisión.

Detección automática del sitio actual


Browsers Dictionary rastrea en segundo plano la dirección de la página que estás viendo actualmente, por lo que siempre sabe qué diccionario de sitio —si lo hay— debe aplicarse. Este rastreo se actualiza:


- Cuando cambias a una ventana del navegador.
- Cuando el foco se mueve dentro de la página (se comprueba no más de dos veces por segundo para evitar trabajo innecesario).
- En el momento en que una nueva página termina de cargarse.


Nunca necesitas hacer nada para activar esto — sucede automáticamente mientras navegas.

Coincidencia a través de fragmentos de habla divididos


NVDA a veces anuncia una sola línea como varios fragmentos de habla separados — por ejemplo, el rol de un enlace, el propio texto del enlace y el texto que le sigue. Browsers Dictionary está diseñado para capturar patrones que abarcan exactamente este tipo de límites, de modo que una frase como "mensajes hasta ..." aún se pueda detectar y reemplazar incluso cuando "mensajes" es el texto de un enlace y el resto va inmediatamente después.


Los pasajes hablados muy largos (más de 20.000 caracteres) se omiten por completo en la exploración, ya que buscar patrones en bloques tan grandes añade un procesamiento notable sin ningún beneficio real.

Comprobaciones de seguridad de expresiones regulares


Cada vez que guardas una expresión regular —ya sea para una entrada de palabra o para el patrón de URL de un sitio— Browsers Dictionary la comprueba de dos maneras:


Paso 1 — Comprobación de validez: el patrón debe compilarse correctamente como una expresión regular válida, de lo contrario se rechazará el guardado con una explicación.
Paso 2 — Comprobación de patrones desbocados: el patrón se compara con una estructura conocida que suele causar que las expresiones regulares se ejecuten de forma extremadamente lenta en ciertos textos (grupos anidados repetidos como (x+)+). Si coincide con esta estructura, escucharás un mensaje de advertencia — pero el patrón se guardará de todos modos, ya que esta comprobación no puede garantizar que un patrón sea realmente no seguro, solo que se parece a los que pueden serlo.


Como protección adicional mientras navegas, todas las entradas de palabras con expresiones regulares para una sola frase hablada comparten un presupuesto de tiempo combinado de 0,1 segundos. Si ese presupuesto se agota, cualquier entrada de expresión regular restante para esa frase se omitirá en esa ocasión, para que un patrón pesado no retrase de forma perceptible la voz.

Gestión de sitios y entradas


El diálogo de Opciones muestra todos tus sitios configurados en un lado y las entradas del diccionario del sitio actual en el otro. Desde aquí puedes:


- Añadir, editar o eliminar una entrada del diccionario (también accesible mediante la tecla Suprimir o el menú contextual del botón derecho en la lista de entradas).
- Editar o eliminar un sitio completo (también accesible mediante la tecla Suprimir o el menú contextual del botón derecho en la lista de sitios).
- Importar una lista de entradas desde un archivo JSON directamente en el sitio actualmente seleccionado.

Importación de entradas desde un archivo


Puedes cargar entradas del diccionario de forma masiva en el sitio actualmente seleccionado desde un archivo JSON. El archivo necesita una lista "words" que contenga valores de texto plano o entradas más completas con un patrón, un indicador de expresión regular opcional y un reemplazo opcional.


Las entradas con errores de formato se omiten en lugar de detener toda la importación, y al finalizar se te indicará exactamente cuántas entradas se añadieron frente a cuántas se omitieron. Las expresiones regulares importadas pasan por las mismas comprobaciones de validez y patrones desbocados descritas anteriormente.

Migración automática de configuración


Si Browsers Dictionary detecta diccionarios guardados por una versión anterior del complemento (incluida una publicada bajo el nombre anterior de este complemento), los copia automáticamente a la ubicación de configuración actual la primera vez que se inicia. No se pierde nada, incluso si ya existen entradas en ambos lugares — los sitios coincidentes fusionan sus listas de palabras en lugar de que una copia sobrescriba a la otra.

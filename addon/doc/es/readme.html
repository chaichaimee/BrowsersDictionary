Browsers Dictionary


Tu diccionario de pronunciación personal para cada sitio web, leído exactamente como deseas.


author: chai chaimee

Introducción


Browsers Dictionary te permite crear un "diccionario de pronunciación" personalizado por sitio web para la voz de NVDA. Si un sitio usa palabras, abreviaturas o jerga que NVDA lee de manera extraña, puedes definir un patrón de texto o expresión regular y un reemplazo, y NVDA pronunciará tu reemplazo cada vez que ese patrón aparezca en esa página específica, en todo el sitio web o en cualquier URL que coincida con tu propio patrón.


El complemento funciona automáticamente una vez configurado: supervisa silenciosamente qué pestaña o página del navegador está activa y reescribe en tiempo real el texto que NVDA va a decir, basándose en las reglas que configuraste para el sitio actual.


¿Estás actualizando desde Invisible?
Browsers Dictionary es una versión mejorada del complemento "Invisible". Si actualmente tienes instalado Invisible, simplemente desinstálalo primero, luego instala Browsers Dictionary y continúa usándolo de inmediato. No necesitas volver a realizar ninguna de tus configuraciones de sitios: todas las configuraciones de sitios que configuraste previamente en Invisible se transfieren automáticamente a Browsers Dictionary la primera vez que se ejecuta.

Atajos de teclado


NVDA+Shift+W
Un toque : Abrir la configuración de Browsers Dictionary para el sitio actual
Doble toque : Capturar la URL de la página actual y abrir el diálogo Agregar nuevo sitio

Toca una vez para revisar o editar las entradas del diccionario ya guardadas para la página en la que te encuentras actualmente. Toca dos veces rápidamente mientras el foco está en tu navegador para crear inmediatamente una nueva entrada de sitio utilizando la URL de la página que estás viendo. Si NVDA no puede detectar una URL para un doble toque (por ejemplo, no estás en un navegador compatible), te dirá "No se puede capturar la URL. Asegúrate de estar en un navegador".

Características


Seguimiento automático y en vivo de URL


Browsers Dictionary realiza un seguimiento de la página en la que te encuentras sin que tengas que hacer nada. Actualiza su registro de la URL actual:


- Cuando cambias a una ventana del navegador (Firefox, Chrome, Edge, Brave, Opera o Internet Explorer)
- Cuando una página termina de cargar
- Cuando el foco se mueve a un nuevo elemento, como máximo dos veces por segundo, para mantenerse actualizado sin sobrecargar el navegador


Esta URL es lo que el complemento usa en segundo plano para decidir qué conjunto de entradas de diccionario se aplica a lo que estás leyendo actualmente.

Reemplazo de palabras y patrones por sitio


Para cada sitio que agregues, puedes crear una lista de entradas. Cada entrada tiene:


- Un Patrón: el texto exacto o una expresión regular a buscar
- Un Reemplazo opcional: lo que NVDA debe decir en su lugar. Si se deja en blanco, el texto coincidente simplemente se elimina de la voz
- Una casilla de verificación Usar como expresión regular, para coincidencias de patrones avanzados


Siempre que NVDA esté a punto de hablar texto en una página coincidente, Browsers Dictionary lo compara con tu lista y sustituye las coincidencias antes de que se pronuncie la voz. Las entradas de texto plano se comparan primero (las entradas más largas primero, para evitar solapamientos parciales), seguidas de tus expresiones regulares.

Tres formas de hacer coincidir un sitio


Al agregar o editar un sitio, eliges cuán ampliamente deben aplicarse sus entradas de diccionario:


Solo página única: las entradas se aplican solo a la URL exacta que guardaste.
Todo el sitio web (dominio): las entradas se aplican a todas las páginas del mismo dominio, independientemente de la ruta específica.
Expresión regular: las entradas se aplican a cualquier URL que coincida con un patrón que escribas, verificado desde el principio de la dirección.

Gestión de sitios y entradas


El cuadro de diálogo Configuración (abierto con un solo toque de NVDA+Shift+W) contiene una Lista de sitios y, para el sitio seleccionado, una lista de Entradas. Desde aquí puedes:


- Agregar, Editar o Eliminar una entrada de palabra o patrón, con confirmación antes de la eliminación
- Abrir un menú contextual (o presionar Supr) en un sitio o una entrada para acciones rápidas de Editar/Eliminar
- Editar sitio o Eliminar sitio directamente desde el menú contextual de la Lista de sitios
- Cancelar una edición en curso y volver a agregar nuevas entradas


Agregar un nuevo sitio abre un diálogo dedicado donde configuras su nombre de pantalla, URL y modo de coincidencia; guardar un nuevo sitio reabre inmediatamente el diálogo de Configuración principal para ese sitio para que puedas empezar a agregar entradas de inmediato.

Importar entradas desde un archivo


Puedes cargar entradas masivamente en el sitio actualmente seleccionado usando Importar desde archivo.... Browsers Dictionary lee un archivo JSON que contiene una lista "words", donde cada entrada puede ser una cadena simple (tratada como un reemplazo de texto simple) o un objeto completo con configuraciones de patrón, reemplazo y regex. Después de confirmar, informa cuántas entradas se agregaron y cuántas se omitieron, por ejemplo, porque ya existían para ese sitio.

Advertencias de seguridad de Regex y presupuesto de tiempo


Para protegerte de patrones que podrían congelar o ralentizar la voz:


- Cuando guardas una expresión regular que parece que podría causar un "retroceso catastrófico" descontrolado (ciertos grupos repetidos anidados), NVDA te advierte que el patrón puede ejecutarse lentamente, para que puedas simplificarlo. Esto es una precaución útil, no un bloqueo duro; la entrada aún se guarda
- Mientras habla realmente, Browsers Dictionary permite solo un breve tiempo total de procesamiento para todas las entradas de expresiones regulares en una sola pieza de voz. Si ese presupuesto se agota, cualquier entrada regex restante para esa pieza de voz se omite para que tu voz no se detenga
- Los tramos de texto extremadamente largos no se escanean en busca de reemplazos en absoluto, ya que escanearlos agregaría retraso sin beneficio significativo

Migración fluida desde configuraciones anteriores


Browsers Dictionary busca automáticamente los datos de configuración dejados por versiones anteriores o el nombre anterior del complemento "Invisible", y los fusiona en su configuración actual la primera vez que se ejecuta. Los sitios y las entradas de un diseño anterior se copian sin sobrescribir nada que ya hayas configurado; si ya existe un archivo con el mismo nombre, la copia anterior se guarda como copia de seguridad en lugar de descartarse. Los archivos de sitios duplicados que terminan representando el mismo sitio se fusionan automáticamente, combinando las entradas duplicadas en una sola lista.
